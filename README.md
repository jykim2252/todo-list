# 📋 오늘의 할 일 (Smart TodoList)

날짜(YYMMDD) 지정과 카테고리 분류, 직관적인 일차별 할 일 현황판(오늘 남은 할 일, 내일 해야 할 일)을 제공하는 모던 한국어 TodoList 웹 애플리케이션입니다.

---

## 🚀 주요 기능

1. **날짜(YYMMDD) 지정 및 관리**
   - 할 일 등록 시 `YYMMDD` (예: `261126`) 형식의 6자리 날짜를 직접 입력할 수 있습니다.
   - '오늘', '내일' 퀵 버튼을 지원하여 원클릭으로 날짜를 손쉽게 지정할 수 있습니다.
   - 유효하지 않은 날짜(월/일 범위 초과, 평년 2월 29일 등) 입력 시 자동 보정 및 안내를 제공합니다.
   - 목록 카드에 오늘/내일 전용 하이라이트 뱃지가 적용됩니다.

2. **할 일 범주(Category) 선택 및 필터링**
   - **업무**, **개인**, **건강**, **취미**, **기타** 중 범주를 선택하여 등록할 수 있습니다.
   - 범주별 고유 컬러 뱃지가 할 일 목록에 표시됩니다.
   - 범주 칩(Chip) 필터를 통해 특정 카테고리의 할 일만 즉시 모아볼 수 있습니다.

3. **스마트 현황 대시보드**
   - **오늘 남은 할 일 N개**: 오늘 기한인 미완료 할 일 개수를 전면에 표시합니다.
   - **내일 해야 할 일 N개**: 내일 예정된 할 일 개수를 함께 안내하여 내일 일정을 미리 파악할 수 있습니다.
   - **전체 달성 현황**: 전체 할 일 개수, 완료 개수, 달성률(%) 게이지 바를 제공합니다.

4. **완성도 높은 인터랙션 및 안정성**
   - **인라인 수정**: 할 일 내용, 날짜, 범주를 언제든 인라인으로 수정할 수 있습니다 (Esc 취소 / Enter 저장).
   - **실행 취소(Undo)**: 실수로 할 일을 삭제해도 5초 내 즉시 복원할 수 있는 토스트 알림을 지원합니다.
   - **완료 일괄 삭제**: 완료된 항목만 한 번에 정리할 수 있는 안전 확인 모달을 제공합니다.
   - **로컬 스토리지 자동 저장**: 버전 관리 스키마를 통해 새로고침 시에도 브라우저에 안전하게 영구 저장됩니다.
   - **접근성 및 IME 지원**: 한글 IME 조합 중 Enter 중복 입력 방지(`isComposing`), 키보드 탐색 및 명확한 WAI-ARIA 속성을 준수합니다.

## 🛠️ 실행 및 테스트 방법

### 1. 개발 서버 실행
```bash
npm run dev
```

### 2. 프로덕션 빌드
```bash
npm run build
```

### 3. 단위 및 기능 테스트 실행
```bash
npm test
```

### 4. 빌드 결과물 미리보기
```bash
npm run preview
```

## 💾 저장 방식 및 제한사항

- **저장 위치**: 브라우저의 `localStorage` (`antigravity_todo_app_data_v1` 키)에 저장됩니다.
- **제한사항**:
  - 현재 브라우저 및 기기 로컬에만 보관되며, 클라우드 동기화나 계정 기반 백엔드 연동은 포함되어 있지 않습니다.
  - 브라우저 쿠키/캐시를 완전히 비우면 저장된 데이터가 초기화될 수 있습니다.
